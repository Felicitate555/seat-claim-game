# 这排我占了！— 源代码（v37）

> 大学校园抢座位小游戏。单局 1 分半，走过的空位就归你，别撞上别人占好的座。
> 纯 HTML5 Canvas，**无框架、无构建步骤、无 npm 依赖**，双击就能玩。

- **版本**：`v37`（**《V36 下一阶段》阶段 1~10 + 试玩四轮追加 R1~R3.5**，**已发布上线 2026-10-23**）
  （上一版 **v36** = 对局中新增「暂停 / 退出键」，2026-10-10 发布；现已被 v37 替换）
- **文件数**：6 个，全部自包含（所有画面都是 canvas 画的，**没有任何图片 / 字体 / 音频资源文件**）
- **代码规模**：`game.js` **11 347 行 / 516 KB**，其余为壳
- **体积**：游戏本体 6 个文件共 **716 785 字节（约 700 KB）**；含本说明约 716 KB

## 一、怎么跑

### 方式 A：直接打开（最快）

双击 `index.html` 即可。`file://` 下**单人和本机双人都完全正常**。

### 方式 B：起本地服务器（推荐，联网对战必须用这个）

```bash
# 在本目录下任选一种
python -m http.server 8000
npx serve .
```

然后浏览器打开 `http://localhost:8000/`。

**为什么联网对战要起服务器**：`file://` 协议下 WebRTC / 剪贴板受限，邀请链接也复制不了。
单机和本机双人不需要。

### 方式 C：手机横屏测试

手机与电脑同一局域网，访问 `http://<电脑IP>:8000/`。
窄屏会自动切「紧凑布局」（画布 692×468）+ 触摸摇杆。

## 二、怎么玩

### 键盘

| 操作 | 单人 | 双人 1P | 双人 2P |
|---|---|---|---|
| 移动 | `WASD` 或 `方向键` | `WASD` | `方向键` |
| 招牌技能 | `Q` | `Q` | **`L`** |
| **暂停 / 继续** | `空格` / `Esc` / `P` | 同左 | 同左 |
| 静音 | `M` | `M` | `M` |
| 开始 / 重开 | `空格` / `回车` | 同左 | 同左 |

> ⚠️ 每个角色**只有一个技能**（V1.6 第二阶段收窄），所以键位只有 `Q` 与 `L`。
> 原来的 `E`（1P 第二槽）和 `.`（2P 第二槽）整条摘掉了 —— 按下它们会被静默忽略。
>
> 🔄 **v37 把 2P 的键从 `,` 换成了 `L`**：`L` 在右手食指 / 中指的常规活动范围，
> 从方向键 `→` 左上移一指就到，中文输入法下也是字母键。
> 两套键**本来就有**，用户感知到「只有一个 Q」的真因是**界面和文案只写了 Q** ——
> 所以这轮同时把 HUD 键帽、主提示、双人模式说明、2P 的四张角色卡 `title` 全部补齐，
> 并且收敛成**唯一真值** `SKILL_KEY_LABELS = ['Q', 'L']`（键帽 / 文案 / 规则页 / 探针都从它取）。

> ⚠️ `空格` **有三个身份**，靠当前状态区分：开始页 = 开局、结算页 = 重开、**对局中 = 暂停 / 继续**。
> 三者互不冲突（`canPause()` 只管 `count` / `play` 两态）。`P` 是 v36 新占用的键。

### 移动手感（V1.6 收尾轮）

- **轻点一下方向键 = 走一格**（哪怕手抖按了 200 多毫秒，也只走一格）
- **按住**：先等 **280 ms** 才继续走，之后每 **130 ms** 一格
- 摇杆 / 手指滑动**没有**这段等待，按下即按 130 ms 连续走

> 这段「首次长按延迟」是按**人手**定的，不随角色 / 场景 / 冲刺缩放 ——
> 冲刺只该让**连走**更快，不该让「按一下」变得更敏感。

### 触屏

- 拖动左下角**摇杆**移动；也可以在画面上**滑动**改变方向（轻点 = 走一格）
- 右下角技能按钮（键帽显示各自对应的键：1P `Q`、2P `L`）
- 双人同屏时 2P 摇杆在右下

### 暂停 / 退出（v36 新增）

对局中右上角有一排圆钮：最右是 `🔊`（音效），往左依次是 **`⏸️`（暂停 / 继续）** 和 **`🚪`（退出本局）**。
触屏设备整体右移一档，避免和右下摇杆抢位置。两个钮只在 **倒计时 / 对局中 / 结算页** 出现。

按 `⏸️` 或 `空格` / `Esc` / `P` → 弹出「先歇一会儿」卡片，**整个画面同时压暗一层**：

| 停住 | 照常跑 |
|---|---|
| ⏰ 倒计时 / 上课铃计时 | 🎞️ 粒子飘字（已生成的继续飘完） |
| 🚶 所有 NPC 走位 | 🫧 对话气泡淡出 |
| ⚡ 技能冷却 | 📳 屏幕震动余波 |
| 📋 事件排程（老师巡视 / 清理 / 下课铃 / 期末周） | 🖼️ 画布重绘与暗屏叠加 |
| 📈 连击窗口计时（**不会因暂停而断连**） | 🔊 界面音效 |
| 🎓 新手引导计时 | |

> 🔄 **v37 修了一个真 bug**：连击窗口原来读的是**挂钟**，暂停时挂钟照走 → 一暂停连击就断。
> 现在改读**局内时钟**（暂停时不推进），所以「暂停一会儿回来，连击还在」。
> 这条只影响暂停场景，不暂停时行为逐帧不变（四档指纹 0 变化）。

退出（`🚪` 或卡片里的「退出本局」）**直接回开始页**，本局成绩**不写入**最高分与成就存档。

> ⚠️ **联网对局只有房主（host）能暂停**，客人（guest）按暂停键无反应 ——
> 避免单方面停住造成双方不同步。客人那边如果被暂停，卡片副文案会改成
> 「你这边停住了；联网对局仍在进行。」

### 玩法规则面板（开始页）

开始页右上角有一张 **`📖 玩法`** 小贴纸，点开就是完整的玩法规则
（**v37 从 10 条扩到 11 条**，并配了 **4 张内联 SVG 示意图**：座位分值 / 清理预告 / 学霸预判 / 双人键位）。

三个出口：`✕`、`知道了，开抢！`、或按 `Esc` / `空格` / `回车`。
面板开着时它**独占键盘** —— 在里面按空格不会顺手把一局开起来。
内容多时列表自己滚动，底部会浮出「向下还有更多 ↓」提示。

### 新手引导

**第一次玩**（单人第一局）会自动出三步引导，气泡跟着你操控的角色走：

1. `WASD / 方向键 移动`（触屏设备上换成「拖动屏幕 移动」）
2. `走过空位，座位就归你`
3. `别撞别人的占座`

它不是读一页说明，而是**跟着你的真实操作推进**（走动了 → 占到第一个座了 → 稳住几秒），
最长 30 秒自动收尾。看过一次就记在浏览器里，之后不再出现。

> 想再看一次：浏览器控制台执行 `localStorage.removeItem('zhanzuo_tut_v1')` 再刷新。

### 核心规则

- 走过的空位即被占领，占领越多分越高
- **自己的占座是通路**（V1.6 第一阶段核心改动）：可以随便走回自己占过的格子，
  不会被截停、不会重复计分。所有玩家一视同仁，不依赖任何技能。
- **撞到别人占好的座位 = 出事**（V1.6 第一阶段定稿）：
  - 单人 → 扣 **50 分**并**复位**（`SOLO_PENALTY_ON`，v34 改的）
  - 双人 → 扣 **50 分**（不低于 0）并**原地等 2 秒**，落地后 0.8 秒无敌，避免连续受罚
  - 同一帧里两个人抢同一格 → **输的那一方不判罚**
- **对手的身体和墙只是挡路，不扣分**（只有「座位」才罚）
- 连续占座有**连击加成**（间隔 2.6 秒内继续占则连击 +1）
- **最后 15 秒**进入收尾高潮（当前只在双人模式开）

## 三、游戏内容

### 三个场景（开始页可切）

| 场景 | 机制 | 座位图形 |
|---|---|---|
| 🏫 **教室** | 基准场景，无额外规则 | 方桌 + 椅子条 |
| 📚 **图书馆** | 三区域（安静区 / 插座区 / 讨论区）+ 安静值仪表 | 方桌（阅览桌） |
| 🍜 **食堂** | 四区域（快速窗口 / 双人桌 / 热门档口 / 窗边桌）+ 饭菜产出 + 排队长龙 + 开饭铃 + 新菜上线 | **圆桌 + 圆凳 + 餐盘** |

三个场景不只是换配色：墙面、地板材质、装饰物、座位剪影各有一套。

**图书馆的取舍**：安静区里座位分 ×1.4，但每格步进 ×0.72（磨蹭）；在安静区持续走动会掉
「安静值」（每秒 −13），掉到 25 以下被管理员驱赶 —— 扣 120 分 + 原地罚站 2 秒。

**食堂的节奏**：开饭铃响时全场（含玩家）步进间隔 ×0.6，持续 8 秒 —— 所有人一起冲。

### 四个角色（各有招牌技能，不是单纯数值差异）

| 角色 | 定位 | 被动 | 招牌技能（1P `Q` / 2P `L`） |
|---|---|---|---|
| 🎓 学霸 | 规划型 | 特殊座位 +50% 分 | `学霸地图` 🗺️ 全场高价值座位亮起 8 秒（CD 18s）+ **被动：提前 10 秒看到下一轮清理的逐格名单** |
| 😎 摸鱼大师 | 免疫型 | 免疫负分座与老师盯梢 | `老师来了` 👻 6 秒内可穿过**别人**的占座（CD 20s） |
| 🏃 行动派 | 速度型 | 连击奖励翻倍、移动更快（步进 ×0.88） | `冲刺` 💨 3.5 秒内跑得飞快（CD 16s） |
| 🤝 社交达人 | 辅助型 | 室友每帮占一座 +15 分 | `求助室友` 🙋 室友来帮你占连座 **10 秒**（CD 22s） |

> 🔄 **v37 的学霸预判（R3.4）**：第一次清理在 **30 秒**，学霸从 **20 秒**就开始看到
> **紫色大框 + 框内逐格点亮**（淡紫底 + 白粗边 + 中心圆点）；**自己踩着的那格画空心虚线**
> （意思是「到时不清」）。普通角色只提前 **3 秒**、只有框没有逐格 —— 逐格是学霸的专属。
> 逐格名单**直接复用清理系统自己算出的那份名单**，所以「预告 = 实际」是结构上的保证。
>
> 🔄 **室友（R3 系列）**：帮忙时长 **10 秒**（原来名义 12 秒、实际只活 2.18 秒）；
> **每走一步就占脚下那格**（不再左右扩、不再有延迟）；占下的座位上有
> **青绿虚线内环 + 右上角 🙋 记号**，并且独立成一层画在清理预告之上（否则会被盖掉）。

### 两种模式

- **单人抢座**：自己抢满 1 分半，结算出战绩 + 任务 + 称号 + 成就 + 本局高光（**3 个电脑角色照旧在场**）
- **双人开战**：1P vs 2P 同屏；支持**本机双人**和**邀请好友（联网对决，走 PeerJS）**

> 🔄 **v37：双人默认「纯真人」—— 场上只有你们两个，没有电脑对手**（R3.5）。
> 两人在**同一条横走道**上、隔着中间分坐两边，抢的是同一片座位。
> 想临时要回电脑对手：地址栏加 **`?purepvp=0`**（只有双人模式受影响，单人一字未变）。
> 这个模式本来在阶段 4 就做好了，只挂在 `?purepvp=1` 下面；R3.5 只是**把默认值调转**，一行逻辑没改。

### 局内系统

- **新手引导**：三步，只在单人第一局出现（见上）
- **校园事件**：**一局只跑「管理员清理」这一条线**（V1.6 第二阶段收窄）。
  清理走**固定时间表**：第 **30 秒 / 60 秒**各清一次，**第 27 / 57 秒**先预告名单
  （学霸提前到 **20 / 50 秒**）。
  清理是**两段式**的：预告的是哪些座位、到点执行的**就是同一份名单** ——
  「预告 = 实际」是结构上的保证，不是两处算法凑巧写得一样。
  清理**不会清掉玩家正踩着的那一格**。
  > 🔄 **v37 的集中清理（阶段 2）**：清理不再零散地抹单格，而是**挑最挤的一片 5×5 整片清掉**。
  > 效果：清理后的「碎座位块」连通分量 **29.5 → 2.75**，包围盒 **25.6 → 5.0 格** ——
  > 地图不再被切得七零八落。开关 `EV_CLEAN_CLUSTER_ON`（默认开）。
  > 其余事件**实现都在**，只是默认不在池子里（`EV_ONLY_CLEAN = false` 即可放回）：
  > 点名、老师巡视、室友求助、提前进教室、临时换教室、期末周狂暴、开饭铃、新菜上线。
  > 图书馆与食堂各有专属事件（期末周狂暴 / 开饭铃 + 新菜上线）。
- **任务系统**：一局 **1 个固定任务**（V1.6 第二阶段收窄），面板常驻显示进度。
  完成后**不补新任务**。
- **成就**：跨局累计（后排之王 / 占座狂魔 / 黄金猎人 / 教室地产商 / 路障大师…），存 localStorage

## 四、文件结构

```
这排我占了_v37_源码/
├── index.html          页面骨架 + 全部 DOM 层（开始页 / 玩法规则页 / HUD / 倒计时 / 结算页）
├── style.css           全部样式（含标准版与紧凑版两套覆盖）
└── js/
    ├── game.js         游戏本体：画布绘制 + 玩法逻辑 + 输入 + UI 同步（11 347 行）
    ├── audio.js        WebAudio 音效合成（无音频文件，全部用振荡器现场合成）
    ├── net.js          联机对战（PeerJS 封装）
    └── peerjs.min.js   第三方库：WebRTC 信令，本地内置，无需联网安装
```

**加载顺序**（见 `index.html` 末尾）：`peerjs.min.js` → `net.js` → `audio.js` → `game.js`。
`game.js` 是 IIFE，末尾调 `boot()` 启动。

## 五、技术要点

- **无构建**：源码即产物。改完刷新浏览器即可，没有打包 / 转译步骤。
- **无资源文件**：座位、角色、黑板、食堂取餐台、图书馆公告栏全是 canvas 矢量绘制，
  连音效都是 WebAudio 振荡器合成的。所以整个游戏只有 6 个文本文件。
- **自适应**：`#frame` 整体 `transform: scale(var(--fit))` 等比缩放适配任意视口；
  宽高比偏窄时切「紧凑布局」（画布 692×468）并启用触摸摇杆。
- **画布坐标系与 CSS 是同一个空间**：`frame.style.width = CW`，标准版 `S36(v)=v`、
  紧凑版 `S36(v)=0.778v`。所以 `FONT_S.task = 12` 和 CSS 里的 `12px` 屏幕上一样大。
- **字号两条梯队**：画布内文字走 `game.js` 的 `FONT_S` 六档角色（h1/h2/hud/task/warn/reward）；
  界面文字走 `style.css` `:root` 里的 23 档 `--fs-*` 令牌。**模块里不写裸字号**。
- **确定性随机**：事件 / 任务 / 食堂热门位各用**独立随机流**（`evRand` / `taskRand` / `hotRand`），
  互不干扰；三者都支持种子覆盖（见下）。
- **视觉规范**：危险提示统一走 `DANGER_STYLE` 一张表（色 / 描边宽 / 闪烁频率三档），
  目标提示另立 `TARGET_STYLE` —— 「去这里」和「别去那里」不能用同一色相。
  > 🔄 **v37 新增第三种语义：紫色 = 「这里要没了」**（清理预告 / 学霸预判）。
  > 三种颜色分工：**琥珀 + 分值药丸 = 去抢这里**｜**红 / 橙 = 别去**｜
  > **紫描边 + 淡底 + 圆点、无分值 = 这块马上清掉**。靠「有没有分值药丸」区分而不是靠色相微差。
- **横幅分级**：重要事件用大号带底板的横幅，一般提示用小号轻量样式。
  判据写在**调用点**（`addBanner` 的第 6 个参数），**不看文案** ——
  因为文案会按场景改写（图书馆里「老师巡视中」会变成「管理员巡视中」）。
- **可复现的回归**：`../测试台/` 里有**四档确定性指纹回归**（默认 / `--events` / `--v2` / `--v16`），
  记录每局 720 帧的状态摘要；任何改动后**这四档必须 0 变化**（除非改动本身就该改行为，
  那时要用 `--legacy-ai` 之类的反向开关先证明「变化只等于那一件事」）。

## 六、调试开关

### URL 参数

| 参数 | 作用 |
|---|---|
| `?touch=1` / `?touch=0` | 强制开关触摸模式（分享测试链接时有用） |
| `?room=xxxx` | 直接进入指定联机房间 |
| **`?purepvp=1` / `?purepvp=0`** | **（v37）双人是否「纯真人」**。默认 `1`（无电脑对手）；`0` = 退回「双人也有 NPC」的老行为。**只影响双人** |

### 缓存戳

## 七、注意事项

- ⚠️ **`Math.random()` 的调用序列是玩法的一部分**（它同时决定 NPC 走位）。
  改代码时**不要增减任何 `Math.random` 调用** —— 哪怕只是「少画一个飘字」，
  只要顺手删掉一次调用，整局随机序列就会重排，NPC 走位、座位分布全变。
  这也是仓库里有「四档确定性指纹回归」的原因 —— 详见 `../测试台/`。
  > ⚠️ **量的时候要排除注释**：`grep -c 'Math\.random()'` 会把**提到这个词的注释行也算进去**
  > （2026-10-10 就因为这个虚惊一场）。正确口径是数**非注释代码行** = **15 行 / 17 个调用**，
  > 且判据是「逐条内容 + 顺序 diff 为空」，不是「总数相等」。
- ⚠️ 微信内置浏览器可能拦截部分能力（剪贴板 / 联网对战），建议用系统浏览器。
- ⚠️ **本目录是「v37 = 线上版」的快照**。2026-10-23 发布，线上 `?v=37`；
  本快照与发布时的开发目录 `../这排我占了/` 逐字节一致，也与**线上 `js/*.js` 逐字节一致**
  （`game.js` md5 `376561c0…`，curl 实测）。
  > 📌 线上 `index.html` 比本地**固定大 575 字节** —— 网关会注入一段统计脚本。
  > **别拿字节数当校验判据**，要么比 `js/*.js` 的 md5，要么比 `?v=` 与关键符号。
  > 📌 **快照刻意不跟开发树走**。之后开发目录继续往前走，本副本保持不动；
  > 发新版要**另建 `_vNN_源码/`**，绝不就地覆盖。
  > 📌 跑像素 A/B 时**不要 `cp` 开发树覆盖任何快照**（2026-10-10 真栽过），
  > 把基线复制到一次性 `_tmp_xxx/` 用完即删。
- 开发与测试仍在 `../这排我占了/` 进行。

**四条设计口径**（都是踩过坑才定下来的）：

1. **「预告 = 实际」靠复用同一份名单，不靠两处写得一样** ——
   学霸预判直接读清理系统自己算出的 `win.occ`（窗口内会被清的座位下标），
   不自己再扫一遍地图。这样即使以后规则改了，预览和正式也不可能不一致。
2. **逐格预判只给学霸** —— 普通角色仍只提前 3 秒、只有框。这是「学霸的规划型」这个定位的落点，
   不是全局 UI 加强；否则角色差异会被抹平。
3. **室友占座记号必须走雪碧图缓存** —— 第一版逐格现画读到 **+1.956 ms/帧（11.7% 预算）**，
   缓存后回到噪声内。**这类「每帧 N 次小绘制」的代码，写完先量帧开销再谈好不好看。**
4. **双人纯真人 = 改默认值，不是加分支** —— 机制在阶段 4 就已经写好并且回归过，
   R3.5 只是把 `PURE_PVP_TEST_MODE` 从 `false` 改成 `true`。
   **代价是：所有「依赖旧默认值」的断言会同时变红**（本轮红了 6 处），
   要逐条判「是它空转了，还是我真改坏了」—— 这一轮就靠这个挖出了两条**从阶段 2 起就空转的死断言**。
